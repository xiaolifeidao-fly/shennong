用户协议

第一条 协议主体与适用范围
1.1 本协议由【淄博一滴水电商有限公司】（以下简称 "我方 / 平台"）与使用本粮食收购信息管理小程序的粮食收购企业（以下简称 "用户 / 收购方"）共同订立。
1.2 本小程序仅为粮食收购企业提供农户收购信息登记、数据存档、数据辅助核算服务，仅面向具备粮食收购经营资质的企业法人使用，农户信息由收购企业自主录入、上传。
1.3 用户点击 "同意并继续"、登录 / 注册小程序账号，即视为完整阅读、完全理解并自愿接受本协议全部条款，受本协议法律约束。若用户不同意本协议任意条款，应立即停止使用本小程序全部功能。

第二条 服务内容
2.1 我方提供小程序线上数据存储、信息录入、数据导出功能，支持收购企业录入农户姓名、身份证号、收购地址、粮食品种、收购重量、收购单价、结算金额等收购业务数据。
2.2 小程序数据仅作为收购企业开具农产品收购发票、向税务机关申请发票领用额度的业务台账辅助材料，不替代税务机关法定申报、备案流程。
2.3 我方仅提供技术存储载体，不参与农户与收购企业的粮食交易，不审核交易真实性，交易法律责任、税务合规责任全部由收购企业自行承担。

第三条 用户（粮食收购企业）权责
3.1 用户保证自身具备合法粮食收购经营资质，录入小程序的农户身份、粮食交易信息均为真实、合法、有效，不存在伪造、虚构农户信息、虚假交易等行为。
3.2 用户承诺已取得对应农户完整授权，方可录入、存储农户身份证号、姓名、住址等个人信息，承担农户个人信息收集、使用的全部告知、授权义务，独立承担侵犯农户隐私权、个人信息权益的全部法律责任。
3.3 用户仅可将小程序内存储数据用于农产品收购发票开具、税务机关发票额度申请、内部收购台账留存，不得将农户信息、交易数据出租、出售、非法提供给第三方。
3.4 用户负责保管自身小程序登录账号、密码，账号下所有操作均视为用户本人行为；因账号泄露、转借产生的信息泄露风险、法律责任由用户自行承担。
3.5 用户应当遵守《个人信息保护法》《税收征收管理法》《发票管理办法》等法律法规，独立承担税务申报、票据开具产生的行政、民事、刑事责任。

第四条 平台权责
4.1 我方负责小程序系统稳定运行、服务器数据加密存储，采取行业标准安全技术措施保护存储的农户信息、收购交易数据。
4.2 我方仅根据用户操作指令提供数据录入、导出服务，不主动调取、使用、对外泄露用户存储的农户个人信息，无合法司法文书不得向任何第三方移交数据。
4.3 我方有权对小程序功能迭代升级、系统维护，维护期间临时暂停服务的，将提前线上通知用户；因不可抗力、第三方网络故障导致服务中断，不承担赔偿责任。
4.4 我方发现用户存在虚构交易、非法倒卖农户信息、利用小程序从事涉税违法活动的，有权立即封禁账号、留存操作日志，并向税务、公安等监管机关移交线索。

第五条 数据存储与使用限制
5.1 小程序存储的收购业务数据、农户个人信息，存储期限遵循《税收征收管理法》账簿保管期限规定；用户可随时申请导出、删除名下全部数据。
5.2 我方不会超出本协议约定范围使用农户个人信息，不会利用农户信息开展广告推送、商业营销等无关业务。

第六条 免责条款
6.1 因用户虚构粮食交易、未取得农户信息授权、虚假填报收购数据引发的税务处罚、农户索赔、行政处罚、刑事处罚等全部由用户自行承担，我方不承担任何连带责任。
6.2 用户自行操作失误、账号被盗、内部人员泄露农户信息造成的损失，由用户独立承担。
6.3 因自然灾害、电信网络故障、监管政策调整等不可控因素导致小程序临时无法使用，我方不承担损失赔偿。

第七条 协议变更、终止
7.1 我方有权根据法律法规更新本协议，更新后将在小程序内公示，用户继续使用即视为接受更新后条款。
7.2 用户注销账号、与我方终止合作协议的，我方将配合删除该用户名下全部农户及交易数据；用户存在违法记录的，相关操作日志将按监管要求留存备查。
7.3 用户违反本协议第三条约定，我方有权单方面永久封禁账号、终止提供全部服务。

第八条 争议解决
因本协议产生的全部纠纷，双方优先协商解决；协商不成的，提交我方住所地人民法院诉讼管辖。

第九条 其他
9.1 本协议自用户点击 "同意并继续" 之日起生效，长期有效。
9.2 本协议条款若部分被认定无效，不影响其余条款法律效力。
